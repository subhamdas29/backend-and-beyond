# Backend to Fullstack Notes

Welcome! This repository serves as a personal knowledge hub and reference guide documenting my transition from backend engineering to full-stack development.

Here, I aggregate practical notes, architecture snippets, key concepts, and lessons learned while expanding my skills across frontend frameworks, system design, modern tooling, and end-to-end web applications.

---

## About This Repository

- **Content Source:** Built using a combination of my own hands-on experience, real-world project learnings, and synthesized insights generated with AI assistance (Claude).
- **Purpose:** A quick-reference playbook for developers with a strong backend background looking to bridge the gap into full-stack development.
- **Topics Covered:** enough HTML and CSS for backend developers, JavaScript DOM manipulation
